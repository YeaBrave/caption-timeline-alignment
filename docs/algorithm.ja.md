# 字幕アライメント研究

Subtitle Alignment Research

[中文](algorithm.zh.md) · [English](algorithm.en.md) · [日本語](algorithm.ja.md)

これは独立した「原稿優先（manuscript-first）」の字幕アライメントの説明と、単体で実行できる実装です。扱う問題は、完成した原稿と、時刻付きの認識語列があるとき、原稿をタイムラインへ揃え、字幕キューに分割することです。

原則：

1. **原稿だけが字幕テキストの出典である。** 認識結果は時刻だけを提供し、誤認識や同音の語は字幕に書きません。
2. **動的計画法で認識語を原稿へ埋め戻す。** 原稿を文字列とみなし、各認識語を正確に一致させる部分文字列とします。できるだけ多くの認識語をヒットさせつつ、原稿側の未認識区間や、一致できない認識語を飛ばせるようにします。
3. **時刻はヒット結果から埋め戻す。** ヒットした区間は、対応する認識語の開始・終了時刻を使います。ヒットしなかった区間は、両側にアンカーがあれば文字数に応じて補間し、推定として印を付けます。アンカーが足りない場合は揃えられないと印を付けつつ、原稿の文言と順序は残します。
4. **句読点、字数、尺に従ってキューを切る。** 二つのアンカーのあいだの間（ま）で切ることを優先します。短すぎるキューはまとめてもよいですが、字数の上限は超えません。キュー間の隙間は閉じてもよく、重なりは記録するだけにし、時刻は変更しません。

本説明は、独立に実装できる考え方だけを述べます。商用ソフトのバイナリ、メモリアドレス、内部シンボル、アンパック手順は含みません。

任意の中国語分かち書き依存は [CREDITS.md](CREDITS.md) を参照してください。
