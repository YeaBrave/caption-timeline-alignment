# 字幕アライメント研究

Subtitle Alignment Research

[中文](algorithm.zh.md) · [English](algorithm.en.md) · [日本語](algorithm.ja.md)

これは独立した「原稿優先」（manuscript-first）の字幕アライメントの説明で、単独で実行できる実装が付きます。扱う問題は、完成した原稿と、タイムスタンプ付きの認識語列があるとき、原稿をタイムラインに揃え、字幕キューへ分割することです。

原則：

1. **原稿が字幕テキストの唯一の出典です。** 認識結果は時間だけを提供します。誤認識や同音の語は字幕に書き込みません。
2. **動的計画法で認識語を原稿に埋め戻します。** 原稿を文字の列とみなし、各認識語を正確に一致させる部分文字列として扱います。目標はできるだけ多く一致させることであり、原稿側の未認識区間や、一致できない認識語はスキップできます。
3. **時間は一致結果から補完します。** 一致した区間は、対応する認識語の開始と終了を使います。両側にアンカーがある未一致区間は、文字数に応じて 2 つのアンカー間で補間し、推定として標記します。アンカーがない区間は揃えられないと標記しますが、原稿の文言と順序は残します。
4. **句読点、文字数、長さでキューを分割します。** 2 つのアンカーの間の間（ま）での分割を優先します。短すぎるキューは結合できますが、文字数の上限は超えません。キュー同士の隙間は閉じることができ、重なりは記録するだけで時間は書き換えません。

この説明は独立して実装できる考え方だけを述べます。商用ソフトのバイナリ、メモリ番地、内部シンボル、展開手順は含みません。

任意の中国語分かち書きの依存関係は [CREDITS.md](CREDITS.md) を参照してください。
