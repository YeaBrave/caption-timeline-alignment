# 字幕对齐算法研究

英文标题：Subtitle Alignment Research

这是一份独立的文稿优先（manuscript-first）字幕对齐说明，并附可独立运行的实现。它处理的问题是：已有完整文稿，以及一串带时间戳的识别词，如何把文稿对齐到时间轴上，再切成字幕条。

原则：

1. **文稿是字幕文本的唯一来源。** 识别结果只提供时间，错误或同音的识别词不会写进字幕。
2. **用动态规划把识别词嵌回文稿。** 将文稿视为字符序列，把每个识别词当作要精确匹配的子串，目标是尽量多地命中识别词，同时允许跳过文稿中的未识别片段，或跳过无法匹配的识别词。
3. **时间由命中结果回填。** 命中的片段使用对应识别词的起止时间；未被命中的片段，若两边都有锚点，则按字数在两个锚点之间插值，并标记为估算；缺少锚点的则标记为无法对齐，但仍保留文稿原文和顺序。
4. **再按句读、字数和时长切条。** 优先在两个锚点之间的停顿处切开，过短的条目可以合并，但不能超出字数上限。条与条之间的空隙可以闭合，重叠只记录、不改时间。

本说明只描述可独立实现的思路，不含商业软件的二进制、内存地址、内部符号或拆包步骤。
